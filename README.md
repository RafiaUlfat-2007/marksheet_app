📝 Marksheet Calculator App
A responsive marksheet calculator app built with HTML, CSS, and JavaScript.
🔗 Live Demo: Click Here

🛠️ Technologies Used

HTML
CSS
JavaScript


✨ Features

📚 Enter marks for 5 subjects (Math, Computer, English, Physics, Urdu)
🧮 Auto calculate total marks & percentage
🎓 Display Grade based on percentage
📊 Progress bar to visualize result
💬 Remarks (Pass / Fail / Excellent)
🌙 Beautiful dark & light panel design
📱 Fully responsive design
